# 主流 AI 视频与生图模型提示词实战手册

在编写分镜提示词时，根据用户指定的目标平台自动适配语法细节；若用户未指定平台，采用兼容 **即梦 Seedance / 可灵 Kling / Vidu** 的通用中文高精度电影提示词结构，并在关键镜头补充平台专属技巧。

## 一、 首帧生图模型（锁构图、锁光影、锁质感）

### 1. 通用首帧生图公式
`[画质与美学风格] + [景别与拍摄角度] + [画幅比例] + [主体身份引用与起始静态姿态] + [服装/道具锚点] + [环境空间与背景层次] + [光影色温与布光方向] + [镜头焦段与景深质感]`

* **正面描述原则**：所有图像模型对否定词（如“房间里没有开灯”、“街上没有车”）理解极差，反而容易画出灯和车。一律改写为**正向视觉结果**（如“漆黑幽暗的房间，仅有窗外漏进的微弱冷蓝夜光”、“空旷寂静的凌晨街道”）。
* **防野生乱码文字**：未命名的招牌、屏幕、纸张极易被 AI 脑补出鬼画符文字。若不需要文字，显式写明 `干净纯色墙面，无任何文字水印`；若必须生图带少量大字（如 GPT-Image / 即梦文字版），用双引号包裹准确词组并注明载体位置（如 `霓虹灯牌上清晰显示中文“深夜食堂”`）。

### 2. 资产一致性基准图建议
* **单人设定卡**：优先出 **16:9 半身像** 或 **三视图（正面 + 左侧45度 + 全身站姿）**，面部占画面 30%～50%，光线均匀或贴合主场景色温，避免墨镜、夸张遮挡或多人同框。
* **多状态衍生角色**：用首张角色基准图走「图生图 / 局部重绘 / 角色编辑」，提示词开头写明 `保持参考图人物五官骨相与脸型完全一致，仅将年龄调整为...，服装更换为...`。

## 二、 主流视频生成模型语法与避坑指南

### 1. 即梦 Seedance（Seedance 2.0 / 2.5 系列）
* **参考图序列强绑定**：多图参考模式下，上传顺序严格对应 `@图1` / `@Image1`、`@图2` / `@Image2`。在分镜引用栏写清：`@图1（角色A）+ @图2（角色B）+ @图3（场景1）`，每个参考槽位只承担单一职责。
* **字数甜区**：单条运动 Prompt 控制在 **40～120 中文字（英文 < 150 词）** 最稳；堆砌冗长形容词会导致模型丢弃后半段动作指令。
* **防自动乱切镜头**：Seedance 倾向于自动多机位切镜；若单镜需要一镜到底，运动 Prompt 末尾加上 `一镜到底，不切镜头（one continuous shot, no cuts）`。反之，若想在单次生成内做硬切，可用 `[00:00-00:02] ... [00:02-00:05] ...` 时间戳语法。
* **口型与原生音效**：
  * 需要人物开口说话对口型时，在运动 Prompt 中将台词用双引号标出（单句不超过 12 个字），如：`少年激动地张口大喊：“快上快上！”`。
  * 若后期需要自己配音（TTS/真人配音）或铺纯净 BGM，提醒关闭 `原生音效生成（generate_audio: off）` 或在后期静音原视频轨，防止原生环境杂音串音。

### 2. 可灵 Kling（Kling 3.0 / 4.0 · 创意工坊主体参考 Elements）
* **多主体同框（Elements）**：2～3 人交互戏（如网吧并排开黑、对手戏争吵），先将角色基准图注册为独立「主体元素」，在提示词中明确左右站位坐标（`画面左侧穿红球衣的少年...，画面右侧穿白T恤的少年...`），严禁只写“两个人看着彼此”导致左右衣服互串。
* **运镜控制力极强**：擅长执行明确的单轴电影运镜，如 `镜头缓慢向前推进至面部特写`、`低角度环绕拍摄`、`手持摄影微晃临场感`。切忌同时写“一边环绕一边拉远再向上摇移”。
* **首尾帧模式（Start & End Frame）**：极适合**时空转场、昼夜交替、推门入画、情绪骤变**。首尾帧构图透视差距不宜过大（建议控制在 3～5 秒内能自然物理过渡的范围）。

### 3. Vidu（参考生视频 Reference-to-Video）
* **强项**：无需先费力拼合多人首帧图，可直接上传 `角色A图 + 角色B图 + 场景图` 三张独立资产图，直接通过提示词将人物放入场景中演戏。
* **写法要点**：提示词第一句必须先把每个上传主体锚定到空间位置，再写动作交互，最后补一条 `保持人物面部特征与服装全程一致`。
* **二次元与国风动漫表现优异**：做漫剧、修仙、热血番剧分镜时，可在风格词中加入 `高帧率番剧作画，赛璐璐光影，速度线张力，关键帧爆发感`。

### 4. Veo / Sora / Runway（英文原生模型双语适配）
当用户目标工作流包含海外模型时，除中文导演描述外，额外提供精准英文 Prompt：
* 结构：`[Shot Type & Lens] + [Subject & Action Physics] + [Environment & Lighting] + [Single Camera Move] + [Preserve: identity/wardrobe anchor]`。
* 慢动作标准写法：不写 `very slow`，写 `recorded at 240fps, played back at 24fps, crisp motion physics`。

## 三、 高频翻车场景急救对照表

| 易翻车场景 | 错误写法（必崩） | 零翻车拆解方案（推荐） |
| :--- | :--- | :--- |
| **多人同框串脸/换衣服** | “三个好朋友在网吧一起激动欢呼” | 明确左中右坐标 + 衣服颜色强绑定：`左侧红球衣少年拍桌，中间白T恤少年前倾，右侧黑T恤青年微笑`；超过 3 张清晰正脸时拆成正反打或远景剪影 |
| **复杂连续长动作** | “走进门放下包走到桌前坐下开机点开图标”（1镜塞6个动作） | 按剪辑点拆成 3 个 3～4 秒短镜头：`镜01 推门入屋` → `镜02 卸包坐下开机亮屏` → `镜03 眼神特写切鼠标双击` |
| **剧烈高速打斗/按键** | “手指极快地按键盘” | 拆成 **1.5秒手部微距特写 + 2秒人物面部发力特写 + 实拍/特效受击反馈**，靠剪辑节奏制造速度感，不靠单镜硬生鬼畜快动作 |
| **屏幕/聊天框/招牌文字** | 让 AI 视频直接生成手机微信长聊天记录或游戏战绩面板 | 改为 `[真实设备录屏/截图 + 剪映/PS贴字]`，若需带人物入画则用 `过肩镜头背景虚化屏幕光斑 + 切全屏高清UI特写` |
| **跨越时空的无缝转场** | 靠文字硬写“画面一转变成五年后” | 使用 **「同构图垫图 Match Cut」**：截取上一镜尾帧 → 图像编辑锁死人物坐标与姿势，仅重绘衣服和背景 → 作为下一镜首帧 |
