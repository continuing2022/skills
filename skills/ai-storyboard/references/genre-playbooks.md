# 六大高频题材 AI 视频分镜节奏公式

针对不同内容赛道，自动匹配最佳画幅、单镜均长、戏剧结构与混合制作策略：

---

## 1. 剧情微电影 / 青春怀旧 / 情感共鸣短片（60s - 120s）
* **推荐画幅**：`16:9 横屏` 或 `2.39:1 变形宽银幕`（电影感最强）
* **单镜均长**：3.5s ～ 5.5s（留足情绪呼吸与微表情发酵时间）
* **经典五幕黄金结构**：
  1. **当下冷调日常（0%-20%）**：具象小动作切入（归家、加班、翻旧物），冷光低饱和建立孤独感。
  2. **记忆触发器（20%-35%）**：老物件/旧图标/老照片特写 + `J-Cut 声音先行` 唤醒感官。
  3. **往昔高燃/温暖盛景（35%-65%）**：暖调高饱和群像或高光互动，快节奏切镜（2.5s-3.5s/镜）将情绪推至顶点。
  4. **灵魂匹配转场与释怀（65%-88%）**：用 `动作匹配 Match Cut + 绝对静音留白` 一刀切回现实，用克制的微笑或坚定动作完成人物弧光。
  5. **余韵定格 / 反差彩蛋（88%-100%）**：要么深情留白收尾，要么接 `假结局黑屏 + 现实破防彩蛋` 兼顾催泪与爆笑传播。

---

## 2. 竖屏精品短剧 / 漫剧 / 悬疑反转爽剧（单集 45s - 90s）
* **推荐画幅**：`9:16 竖屏`（人物构图重心集中在画面上 1/3 至正中，底部预留 20% 字幕安全区！）
* **单镜均长**：1.8s ～ 3.5s（极快节奏，严禁超过 4 秒无信息增量空镜）
* **黄金结构**：
  * **前 3 秒强冲突钩子（Hook）**：直接从巴掌落下、身份揭穿、诡异规则弹出、或危机贴脸的第一帧开篇，绝不铺垫背景！
  * **中段三连拉扯**：压迫/嘲讽（仰拍反派近景 + 俯拍主角隐忍特写）→ 关键道具/线索特写 → 局势逆转。
  * **结尾断章钩子（Cliffhanger）**：在真相揭晓前半秒或大招释放瞬间硬切黑屏卡点，引导滑入下一集。

---

## 3. 商业广告 / 品牌 TVC / 电商产品大片（15s - 45s）
* **推荐画幅**：`16:9`（品牌TVC）或 `9:16`（信息流投流素材）
* **核心铁律（产品零变形）**：**绝对禁止直接用纯文生图捏造真实在售商品包装与 Logo！**
  * 资产准备：用**真实产品白底棚拍高清实拍图**作为唯一产品参考资产（或首尾帧贴入真实产品抠图），AI 只负责生成周围飞溅的水花、流光、场景人物与微距氛围。
* **四段式转化结构**：
  1. **痛点/感官冲击（0-3s）**：微距质地特写或日常痛点夸张放大。
  2. **产品高光亮相（3-10s）**：高速流体/光影围绕真实产品主体运动（`240fps 升格慢动作质感`）。
  3. **使用场景与情绪体验（10-22s）**：模特使用前后的光影状态对比。
  4. **品牌落版 Packshot（最后 3-5s）**：干净构图定格 + 后期实贴高清品牌 Logo 与 Slogan 字幕。

---

## 4. 游戏 / IP 燃向混剪与宣传片（45s - 90s）
* **混合制片核心**：**`[真人/CG叙事镜头]` + `[实机高光录屏/真实UI截图]` 无缝穿插**！
  * 真人/角色镜头负责**情绪张力**（按键特写、瞳孔反光、嘶吼指挥、赛后击掌/破防）。
  * 复杂连招、团战技能、UI 界面、比分公屏一律采用 **`[实机高清录屏/自定义房间摆拍截图]`**，真实感与玩家共鸣度远超纯 AI 硬捏。
* **声画绑定技巧**：用游戏内标志性音效（闪现、大招语音、进入队列声、打信号 Ping 声）作为跨时空转场的节拍器。

---

## 5. 奇幻科幻 / 国风仙侠 / 动画概念预告（60s - 120s）
* **视觉策略**：大开大合的景别对比——用 **`16mm 极广角大远景`** 展现巨物感与世界奇观，紧切 **`85mm 眼部/兵器微距特写`** 展现宿命感。
* **打斗戏防崩坏拆解法**：AI 单镜无法稳定生成长达 8 秒的多回合招式拆解，必须按武术剪辑逻辑拆分为：
  `蓄力起势特写（2s）` → `兵器出鞘寒光掠过极特写（1.5s）` → `双方交错瞬间慢动作定格首尾帧（2.5s）` → `落地衣摆翻飞与环境震裂反馈（3s）`。

---

## 6. 音乐情绪 MV / 歌词视觉短片（60s - 180s）
* **剪辑脊梁**：以音乐小节与乐句为剪辑尺，**切在乐句换气点与重音气口上**，切忌机械地每个鼓点都硬切导致视觉疲劳。
* **视觉母题（Motif）**：全片贯穿 1 个核心视觉符号（如一束光、一趟列车、一把红伞、不断变换场景但保持同一奔跑姿势的主角），副歌（Chorus）每次出现时升级视觉奇观密度，最震撼的一帧留给最后一段副歌最高音。
